前言

本篇承接上篇 Java 常用类，整理 Java8 全新日期时间类、Math 数学工具、Random 随机数、BigInteger 大数类 全套实操代码，无表格、纯干货，适合期末复习、基础巩固与博客记录。

一、Java8 全新日期时间类（推荐使用）

旧版 Date、Calendar 存在线程不安全、API 混乱问题，Java8 推荐使用 java.time 包全套类。

  1. LocalDate 本地日期（仅年月日）

  2. LocalTime 本地时间（仅时分秒）

  3. LocalDateTime 日期+时间（最常用）

二、日期时间格式化与解析

用于 时间转指定格式字符串、字符串转回时间。

三、日期时间差值计算

  1. 日期间隔（年月日差距）

  2. 时间间隔（时分秒差距）

四、Math 数学工具类

全部为静态方法，无需 new 对象，直接调用，用于常规数学计算。

五、Random 随机数工具类

相比 Math.random() 功能更丰富，支持多种类型随机数。

六、BigInteger 超大整数类

普通 int、long 有数值范围限制，处理超大整数运算必须用 BigInteger，支持加减乘除取余。

整体小结

  1. 日期处理优先使用 Java8 的 LocalDateTime、LocalDate、LocalTime，简洁安全；
    ​
  2. DateTimeFormatter 统一解决时间格式化、解析问题；
    ​
  3. Math 用于简单数学计算，Random 用于灵活随机数生成；
    ​
  4. BigInteger 专门解决超大数值超出基本数据类型范围的运算场景；
    ​
  5. 以上所有类均为 Java 开发、期末考试、项目开发高频基础类
