一、什么是反射？
Java 反射机制（Reflection）是指：程序在运行状态中，可以获取任意类的所有属性和方法，也能直接调用任意对象的属性和方法，这种“动态获取信息并调用对象方法”的能力，就是反射。
简单说：即使在编译期不知道类的名字，运行时也能通过反射找到并使用它。

二、反射的核心原理
Java 程序在运行时，会为每个类生成一个 Class 对象（存放在方法区），这个对象包含了该类的所有信息：
类名、包名
父类、接口
构造方法、普通方法、成员变量
注解等元数据

反射就是通过操作这个 Class 对象，来实现对类的所有信息的访问和调用。

五、反射的优缺点

优点

极大的灵活性：动态加载类、调用方法，适合框架开发（Spring、MyBatis 都用了反射）
解耦：编译期不需要依赖具体类，降低耦合度

缺点

性能较差：反射绕过了编译期优化，比直接调用慢
破坏封装：可以访问和修改 private 成员，安全性降低
可读性差：代码不如直接调用直观，维护成本高

六、反射的常见应用场景

  1. 框架开发：Spring 用反射实现 Bean 的创建和依赖注入
  2. 动态代理：AOP 面向切面编程的核心实现方式
  3. ORM 框架：MyBatis 用反射映射数据库字段到 Java 对象
  4. 单元测试：JUnit 用反射调用 @Test 注解的方法

七、反射的安全与性能优化建议

  1. 尽量使用 Class<?> clazz = 类名.class 代替 Class.forName() ，减少异常风险
  2. 反射调用方法/变量时，缓存 Method 、 Field 对象，避免重复获取
  3. 非必要时不要频繁使用 setAccessible(true) ，会降低安全性
  4. 性能敏感场景尽量用直接调用，反射只作为补充

八、总结

反射是 Java 中一把“双刃剑”：它是框架灵活性的基础，却也牺牲了部分性能和安全性。
理解反射机制，不仅能帮你看懂主流框架的底层实现，也能让你写出更灵活、更具扩展性的代码。
