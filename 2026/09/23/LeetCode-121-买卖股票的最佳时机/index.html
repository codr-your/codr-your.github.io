LeetCode 121. 买卖股票的最佳时机

发表于2026-09-23|更新于2026-09-23|力扣刷题笔记

一、题目描述

给定数组 prices，prices[i] 代表第 i 天股票价格。
只能买入一次、卖出一次，先买后卖，求最大利润。
如果无法获利，返回 0。

二、解题思路

贪心 + 一次遍历

  1. 遍历过程中持续记录历史最低股价（最优买入点）
  2. 每一天用「当前股价 - 历史最低价」计算当天可获得利润
  3. 不断更新全局最大利润
  4. 全程下跌时不交易，利润为 0

三、复杂度分析

  • 时间复杂度：O(n) 数组仅遍历一次
  • 空间复杂度：O(1) 仅常数变量

四、完整代码（Java）

五、代码详解

Integer.MAX_VALUE：初始为 int 最大值，保证第一个价格一定能更新为最低价
遍历所有价格：
当前价格更低 → 更新最低价（找买入时机）
当前价格更高 → 计算利润，更新最大利润
全程只往前遍历，不回头、不重复计算，效率极高

六、样例模拟

输入：prices = [7,1,5,3,6,4]
价格 7 → 最低价 = 7
价格 1 → 最低价 = 1（最佳买入点）
价格 5 → 利润 4，最大利润 = 4
价格 3 → 利润 2，无更新
价格 6 → 利润 5，最大利润 = 5
价格 4 → 利润 3，无更新
最终结果：5

七、总结

核心思想：记录历史最低点，当天价格卖出
一次遍历即可求出单次股票交易的最大收益，是经典贪心入门题。
