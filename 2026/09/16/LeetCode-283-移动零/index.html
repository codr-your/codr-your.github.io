LeetCode 283. 移动零

题目

给定数组 nums，将所有 0 移动到数组末尾，保持非零元素相对顺序，原地操作。
示例：输入 [0,1,0,3,12] → 输出 [1,3,12,0,0]

注释代码

解题总结

1.算法思路：快慢双指针。快指针遍历数组寻找非 0 元素；每当找到非 0，就和慢指针位置元素交换，慢指针右移。一次遍历完成，无需二次填充 0。
2.复杂度：时间 O (n)，仅遍历数组一次；空间 O (1)，原地修改数组，不额外开辟数组。
3.央企 / 国企笔试考点:
数组为引用传递，函数 void 返回，直接修改原数组，不需要 return。
原地算法要求，不能新建数组，是机考高频限制条件。
双指针模板，同类题 LeetCode 27 移除元素思路一致，经常变形考察。
必须保证非零元素原有相对顺序，不可直接排序。
4.易错点：区分 void 原地修改 和 需要返回有效长度的数组题目
