LeetCode 20. 有效的括号

发表于2026-09-27|更新于2026-09-27|力扣刷题笔记
|浏览量:

题目描述

给定一个只包括 '('，')'，'{'，'}'，'['，']' 的字符串 s ，判断字符串是否有效。

有效字符串需满足：

  1. 左括号必须用相同类型的右括号闭合。
  2. 左括号必须以正确的顺序闭合。
  3. 每个右括号都有一个对应的相同类型的左括号。

示例1
输入：s = “()”
输出：true
plaintext
示例2
输入：s = “()[]{}”
输出：true
plaintext
示例3
输入：s = “(]”
输出：false

提示
1 <= s.length <= 10^4
s 仅由括号 ()[]{} 组成

思路

栈的特性：先进后出。

  1. 遍历字符串，遇到左括号，压入栈保存。
  2. 遇到右括号：
    如果栈为空，说明没有左括号配对，直接返回false。
    取出栈顶保存的左括号，判断是否和当前右括号匹配；不匹配直接返回false。
  3. 遍历结束后，如果栈为空，代表全部括号配对成功；否则存在未闭合左括号，返回false。

Java 代码

关键总结

左括号入栈；右括号弹出栈顶进行配对校验。
遇到右括号但栈为空：直接无效。
遍历结束，栈必须为空。
