题目：53. Maximum Subarray（最大子数组和
给你一个整数数组 nums ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。
子数组：是数组中的连续元素序列。

示例

示例1：
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6。
示例2：
输入：nums = [1]
输出：1
示例3：
输入：nums = [5,4,-1,7,8]
输出：23
提示

• 1 <= nums.length <= 10^5

• -10^4 <= nums[i] <= 10^4
说明：本题经典解法是Kadane算法（卡登/卡登斯算法），时间复杂度 O(n)，空间 O(1)。

Kadane 算法 Java 代码

算法思路解释

  1. 维护两个变量：currentSum（以当前位置结尾的最大连续子数组和），maxSum（全局最大）

  2. 每遍历一个数字，判断：前面的子数组和对当前数字有没有增益

如果 currentSum + nums[i] > nums[i]：说明加上前面更好，继续沿用前面子数组

否则：前面的和是负数，直接抛弃前面，子数组从当前元素重新开始

  1. 每次更新完currentSum，都对比更新全局最大值maxSum
    关键点：子数组必须连续，所以currentSum定义一定是以i位置结尾的最大子数组。
    博客笔记总结

复杂度分析

• 时间复杂度：O(n)，仅遍历数组一次，n是数组长度，可以满足 10^5 的数据规模

• 空间复杂度：O(1)，只使用常数额外变量

知识点总结

  1. Kadane（卡登）算法：解决连续子数组最大和的经典贪心算法。

  2. 贪心思想：如果前面一段子数组的累加和为负数，它会拖累后面的总和，直接舍弃。

  3. 边界注意：数组元素可以全部为负数，此时答案是数组中最大的单个元素，代码天然支持这种情况。

  4. 拓展：本题还可以用分治解法，但分治实现复杂、常数更大；刷题优先掌握Kadane。

做题心得
这道题是动态规划+贪心的经典入门题。DP状态：dp[i] 代表以nums[i]结尾的最大子数组和。
状态转移方程：dp[i] = max(nums[i], dp[i-1] + nums[i])
因为每次只需要上一个dp值，所以不需要dp数组，压缩成单个变量currentSum，就是Kadane算法。
