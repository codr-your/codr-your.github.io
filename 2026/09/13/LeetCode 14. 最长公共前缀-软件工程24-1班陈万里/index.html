题目
编写一个函数来查找字符串数组中的最长公共前缀。
如果不存在公共前缀，返回空字符串 “”。
示例 1：
输入：strs = [“flower”,”flow”,”flight”]
输出：”fl”
示例 2：
输入：strs = [“dog”,”racecar”,”car”]
输出：””
解释：输入不存在公共前缀。
提示：
1 <= strs.length <= 200
0 <= strs[i].length <= 200
strs[i] 仅由小写英文字母组成

Java 代码

总结
思路：以第一个字符串作为公共前缀，逐个和数组里剩下字符串对比；如果当前字符串不是以前缀开头，就把前缀最后一个字符删掉，继续判断。
indexOf(prefix) == 0：代表字符串以 prefix 开头。
边界：数组为空返回””；公共前缀缩减到空串，直接返回””。
时间复杂度：O (mn)，m 是公共前缀长度，n 是字符串数量。
