实验3：Python列表、元组、集合

发表于2026-11-05|更新于2026-11-12|Python 实验
|浏览量:

一、实验目的

  1. 深入掌握列表、元组、集合底层特性：可变／不可变、可哈希判定规则，区分“引用不可变”和“元素内容不可变”；
  2. 精通切片语法、步长正负、del切片删除的底层执行逻辑，理解切片删除时索引的计算陷阱；
  3. 熟练运用集合交、并、差、对称差运算，掌握集合推导式、列表推导式；
  4. 能够处理嵌套列表、嵌套元组，准确判断嵌套对象是否可哈希；
  5. 理解集合去重丢失顺序问题，实现保留原始顺序的去重算法；
  6. 具备代码排错能力，独立分析TypeError: unhashable type、切片删除预期不符等疑难问题；
  7. 根据需求自主选择容器，完成小型综合数据处理任务。

二、实验环境

  1. Python 3.x
  2. 开发工具：PyCharm
  3. 无第三方库依赖

三、实验原理

  1. 列表list：动态数组，存储对象引用；切片操作生成新序列，del 列表[切片]原地批量删除；遍历过程中删除元素极易产生漏删。
  2. 元组tuple：不可变指元组内部存储的引用地址不可修改，不限制引用指向的可变对象内部修改；只要元组内任意一个元素是不可哈希对象，整个元组不可哈希。
  3. 集合set：哈希表实现；支持& | - ^四种运算；普通set可变，不能嵌套；固定不变集合使用frozenset（可哈希，可以放进集合）。
  4. 哈希判定：只有生命周期内hash值固定的对象，才是可哈希对象。
  5. 去重两种方案：list(set(ls))简洁但丢失原有顺序；保序去重可利用字典key自动去重，或循环判断实现。
