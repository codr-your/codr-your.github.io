作业说明

homework to blog：编写程序，统计十五五发展规划报告热词频率。
使用 jieba 中文分词库对《十五五规划纲要》文本分词，过滤停用词，统计高频词汇，并可视化词云、词频柱状图。

核心思路

  1. 读取规划纲要文本文件；
  2. jieba精确分词；
  3. 过滤：单字、停用虚词、非中文词汇；
  4. Counter统计词频，按频次降序排序；
  5. 生成词云图 + 高频词柱状图。
