实验简介

本实验完成静态网页新闻爬虫开发，基于 Python 使用 requests + BeautifulSoup4 实现公开网页列表数据抓取；实践 Vibe Coding 迭代式开发工作流：需求澄清、分步生成代码、运行验证、报错反馈迭代、代码审查重构。实现提取文章标题、发布时间、作者、链接字段，将结构化数据导出 CSV 文件；增加 UA 伪装、请求延时、超时重试、字段缺失容错等反爬友好处理；最后将过程式代码重构为面向对象爬虫类。同时拓展思考 JS 动态渲染页面的两种爬取方案，建立爬虫合规意识。

运行说明

执行面向对象版本爬虫程序，运行完成后结果保存至 output/result.csv，终端输出抓取成功条数。

核心实验要点

Vibe Coding 开发流程：拒绝 AI 一次性生成完整大代码；采用「结构化 Prompt 定义需求 → 最小单元代码生成 → 运行验证 → 报错回传修复 → 叠加新功能」闭环迭代。
反爬友好策略：配置 User‑Agent 浏览器伪装，设置 ≥2 秒请求间隔，网络超时自动重试 3 次；字段缺失做容错赋值，避免程序崩溃。
工程化重构：将过程式爬虫代码重构为NewsCrawler类，把请求头、重试次数、延时、目标 URL 封装为类属性，提升代码可读性与可维护性。
拓展思考动态网页爬取：针对 Vue/React 渲染页面，对比抓后端 AJAX 接口、浏览器自动化（Selenium/Playwright）两种方案的代码复杂度与运行效率差异。

实验收获

掌握静态网页爬虫基础开发；学会编写结构化提示词与 AI 协同开发；理解爬虫基础反爬规避手段，增强网络爬虫合规意识；熟悉从原型代码到面向对象工程代码的重构思路，同时学会在 GitHub 组织规范实验项目目录。
