三、知识点总结

  1. 方法定义：修饰符、返回值类型、方法名、参数列表、方法体。
  2. 方法重载：方法名相同，参数列表不同（个数、类型、顺序）。
  3. 参数传递：基本类型传递值，引用类型传递地址。
  4. 递归：方法调用自身，必须有出口，否则栈溢出。
  5. 代码规范：方法功能单一，见名知意，便于复用和维护。
